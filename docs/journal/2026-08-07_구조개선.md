# 2026-08-07 (2차) 디렉토리 구조 개선 + 신규 프로젝트 착수 문서

## 1. PYTHONPATH 하드코딩 제거 (근본 원인 수정)

`PYTHONPATH` 10개 경로 문자열이 12곳에 복붙돼 있었고 **실제로 두 번 장애를 냈다**.
- 배치 bat 에 `agy-gateway` 누락 → 오늘 아침 배치 실패
- 워치독 스크립트 경로 부족 → `ModuleNotFoundError`

### 조치
- `program/src/*.py` 9개를 `program/app/src/autonote/` 패키지로 이동 (git mv, 이력 보존)
  - 평평한 모듈로는 설치가 불가능하다. 모듈명이 `notify`, `watchdog`, `main` 처럼 일반적이어서
    설치 시 충돌한다 (`watchdog` 은 실제 PyPI 패키지명).
- 패키지 내부는 상대 import, 외부 참조(테스트 5개·스크립트 5개)는 `autonote.X` 로 갱신
- 워크스페이스 10개 멤버를 `pip install -e` 로 설치 (uv 미설치 환경)
- 진입점을 `python -m autonote.main` 으로 통일

### 결과
bat 의 경로 문자열, 스크립트의 `sys.path.insert` 블록 5개, 문서 10곳의 PYTHONPATH 안내가
모두 사라졌다. 무관한 디렉터리에서 import 동작 확인.
