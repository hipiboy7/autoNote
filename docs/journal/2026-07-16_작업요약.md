## 3. Google Workspace MCP `docs.writeText` 라이브러리 버그 발견
- 구글 워크스페이스 MCP 플러그인의 `DocsService.ts` 300라인에 최적화용 조건문(`position === 'end' && !tabId`)이 들어있습니다.
- 이 분기에서 Google Docs API의 `insertText` 요청을 보낼 때 location을 지정하지 않아 `No insertion location set` 에러가 무조건 발생하고 있습니다.
- 이번 수동 복구에서는 `position`을 문서의 실제 글자 수(endIndex - 1)로 강제 지정하는 꼼수(Trick)를 활용해 정상 기록하였습니다. 향후 플러그인 소스코드의 수정 빌드가 필요할 수 있습니다.
