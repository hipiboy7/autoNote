# 투자 리서치 노트 시스템 v2 — Antigravity CLI 자동화 (최초 SystemGuide.md 파일)

텔레그램 리서치 채널의 글을 자동으로 수집·정리해 Google Docs에 주제별로 축적하고,
**사용자는 "읽고 생각을 기록하는 것"만 한다.**

- 설계: Claude Fable 5 (2026-07-10)
- 구축·운영: Antigravity CLI (외부 클라우드 인터넷망)
- 심층분석: Claude Opus/Sonnet (회사 폐쇄망, 월 1회, 망간전송)

## 전체 구조

```
[외부망 — 전부 자동]
텔레그램 채널에 글 업로드
  → Antigravity 일일 배치 (스케줄러가 실행)
  → Telegram MCP로 새 글 수집 (마지막 처리 ID 이후 전부 = 누락 자동 복구)
  → AGENTS.md 체계대로 정리
  → Google Docs 00~30에 자동 기록
  → 토요일 배치는 40_리뷰(주간리뷰)까지 자동 생성

[사용자 — 유일한 수동 작업]
업데이트된 Docs 읽기 (매일 5분) + 💭 내 생각 기록

[수동 보조 — 필요할 때만]
Antigravity CLI에 "업데이트" → 배치 누락 보완·즉시 수집
Antigravity CLI에 "추가: ..." → 다른 채널 글·외부 소스(URL/텍스트) 편입

[사내망 — 월 1회]
Docs 다운로드 → 망간전송 → Claude 심층분석 (Claude프롬프트_심층분석.md)
```

## 자동 / 수동 경계

| 작업 | 담당 |
|---|---|
| 기본 채널 새 글 수집·정리·Docs 기록 | 자동 (일일 배치) |
| 주간리뷰 생성 | 자동 (토요일 배치) |
| 배치 누락 복구 | 자동 (다음 실행 시 catch-up) + 수동 "업데이트" |
| 다른 채널·외부 소스 추가 | 수동 명령 "추가: ..." (정리·기록은 자동) |
| **읽기 + 💭 내 생각 기록** | **사용자 (자동화 금지 — 학습의 핵심)** |
| 월간 심층분석 (모순 탐지·프레임 정교화) | 사내망 Claude |

## 파일 구성

| 파일 | 용도 | 사용처 |
|---|---|---|
| `구축지시서.md` | Antigravity에게 시스템을 **구축**시키는 지시 문서. 작업 폴더에서 "구축지시서.md 대로 구축해줘" 한 마디로 실행 | 외부망, 최초 1회 |
| `AGENTS.md` | Antigravity **운영** 규칙 (배치 절차, 정리 형식, 수동 명령). 작업 폴더 루트에 두면 자동 로드 | 외부망, 상시 |
| `Claude프롬프트_심층분석.md` | 월간 심층분석 프롬프트 | 사내망, 월 1회 |
| `시스템가이드.md` | 이 문서 (전체 개요) | 참고용 |

구버전(Gemini 웹/CLI 기준) 문서 — `GEMINI.md`, `Gemini프롬프트_일일정리.md`, `Gemini프롬프트_주간리뷰.md`, `구글드라이브_초기세팅.md` — 는 폐기되었고 내용은 AGENTS.md와 구축지시서로 통합되었다.

## 사용자 루틴

| 주기 | 할 일 | 시간 |
|---|---|---|
| 매일 | 배치 완료 후 추천된 테마 문서 1개 읽기 → 새 항목의 `▶ 💭` 줄에 내 생각 기록 (한 줄이라도) | 5~10분 |
| 수시 | 좋은 글 발견 시 CLI에 `추가: (붙여넣기 또는 URL)` | 1분 |
| 주말 | 자동 생성된 주간리뷰 읽기 | 15분 |
| 월 1회 | Docs 다운로드 → 망간전송 → 사내망 Claude 심층분석 → 결과를 40_리뷰에 반영 | 30분 |

💭 기록은 Docs에서 직접 해도 되고(모바일 포함), CLI에 "MM-DD ○○글에 내 생각 추가: ..."라고 해도 된다.

## 장애·예외 처리

- **클라우드 PC가 꺼져 배치가 안 돈 경우**: 상태 파일(state.json)이 마지막 처리 메시지 ID를 기억하므로, 다음 배치 또는 수동 "업데이트" 때 밀린 글이 전부 처리된다. 유실 없음.
- **배치 시간 외 좋은 글**: "업데이트"로 즉시 수집.
- **Docs 기록 실패**: 정리 블록을 터미널에 출력하므로 수동 붙여넣기로 대체 가능.
- **텔레그램 세션 만료**: 재로그인 필요. Telethon 세션 파일은 계정 로그인 자체이므로 외부 유출 금지.

## 원칙 (변하지 않는 것)

1. 원문은 날짜로 보관, 인사이트는 주제(테마)로 축적한다.
2. 글의 결론이 아니라 저자의 **판단 논리**를 추출한다. 프레임(30)이 진짜 자산이다.
3. 수집·정리는 자동화해도 **읽기와 내 생각 기록은 자동화하지 않는다.**
   전부 자동이면 아무도 안 읽는 노트 더미가 된다. 💭 한 줄이 월간 심층분석의 재료다.
4. 이 시스템은 학습용이다. 종목 추천·매매 판단을 생성하지 않는다.
