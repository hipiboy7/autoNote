### 2.2 테스트 결과 요약
*   **테스트 케이스 수:** 총 6개 통과 / 0개 실패 (Pass 100%)
*   **테스트 케이스 세부 항목:**
    1.  `test_collector_collects_all_new_messages_and_filters_correctly`: 미수집 신규 메시지를 누락(필터) 없이 100% 전부 수집하고 날짜 오름차순으로 정렬하는지 검증하며, 개별 메시지에 대한 리서치 선별(`is_research`)이 올바르게 동작하는지 통합 검증.
    2.  `test_collector_fallback_when_state_file_missing`: `state.json` 상태 파일이 누락되었을 때 기본 상태를 자동 생성하고 24시간 폴백 가동되는지 검증.
    3.  `test_state_manager_handles_corrupt_json`: `state.json` 파일이 깨진 JSON인 경우 `.bak` 백업 파일을 생성하고 안전하게 리셋 복구되는지 예외 처리 검증.
    4.  `test_state_manager_handles_save_error`: 파일 쓰기 권한 부족 등으로 상태 저장이 실패하더라도 에러 콘솔 로그를 남기고 시스템이 비정상 크래시나지 않도록 보호하는지 검증.
    5.  `test_collector_filters_simple_links`: 본문에서 URL 링크 주소를 모두 제외한 실제 코멘트가 3줄 이하이거나 아예 없는 "단순 링크 전송글"에 대해 `is_research`가 올바르게 분석 대상 제외(`False`)로 선별하는지 검증.
    6.  `test_collector_filters_announcements_and_polls`: 본문에 공지 키워드(`[공지]`, `★공지` 등)나 투표/설문조사 단어가 포함된 메시지에 대해 `is_research`가 올바르게 분석 대상 제외(`False`)로 선별하는지 검증.
