# 구축지시서 — Antigravity CLI에게

이 문서는 투자 리서치 노트 자동화 시스템의 **구축 지시서**다.
사용자가 작업 폴더에서 "구축지시서.md 대로 시스템을 구축해줘"라고 하면, 아래 단계를 순서대로 수행하라. 각 단계 완료 시 결과를 보고하고, `(사용자 입력)` 항목은 진행 중 사용자에게 물어서 받아라. 운영 규칙은 같은 폴더의 `AGENTS.md`에 있으며, 구축 완료 후 그 규칙대로 운영된다.

## 사전 확인

1. 이 폴더에 `AGENTS.md`가 있는지 확인. 없으면 중단하고 보고.
2. Google Workspace 플러그인(구 gemini-cli-extensions/workspace)이 설치·인증되어 있는지 확인. 없으면 설치를 진행하고 사용자에게 Google 계정 인증을 안내. **개인 계정**을 쓰도록 안내할 것.

## 1단계 — Telegram MCP 설치

1. Telethon 기반 Telegram MCP 서버를 설치한다. 기본 후보: `chigwell/telegram-mcp` (github.com/chigwell/telegram-mcp). 설치 전 현재 시점에 더 표준적인 대안이 있으면 사용자에게 알리고 선택받아라.
2. `(사용자 입력)` Telegram API ID와 API Hash — my.telegram.org 에서 발급 방법을 안내하라.
3. 최초 로그인(전화번호 인증)을 진행하고 세션 파일 위치를 보고하라.
4. **보안**: 세션 파일과 API 자격증명은 이 PC 밖으로 나가면 안 된다. `.gitignore` 대상이며, 어떤 로그·문서에도 출력하지 마라.
5. MCP 서버를 Antigravity 설정에 등록하고, 연결 테스트로 `(사용자 입력: 기본 채널명)`의 최근 메시지 3개를 읽어 제목만 보고하라 (내용 전문은 출력하지 않는다).

## 2단계 — Google Docs 문서 준비

1. `(사용자 입력)` Drive 상 투자노트 폴더 위치 (없으면 생성 승인 받기).
2. AGENTS.md 문서 매핑표의 문서들을 확인하고, 없는 것은 생성하라:
   - `00_원문보관 2026-07` (매월 배치가 자동으로 새 달 문서를 생성)
   - `10_테마 반도체사이클`, `10_테마 시장심리·수급`, `10_테마 환율·매크로`, `10_테마 금리`
     `(사용자 입력)` 테마 목록 확정 — 위 4개로 시작할지, 수정할지
   - `30_프레임 판단프레임모음`
3. 각 테마 문서 맨 위에 머리말을 넣어라:
   ```
   # (테마명)
   위에서 아래로 시간순 누적. 새 항목은 맨 아래 추가.
   복습: 새 항목이 생기면 문서를 위에서부터 훑어 읽고 ▶ 💭에 내 생각을 기록할 것.
   ━━━━━━━━━━━━━━━━━━
   ```
4. 생성된 문서들의 링크로 AGENTS.md의 매핑표를 갱신하라.

## 3단계 — 상태 파일

`./state.json`을 생성하라:
```json
{
  "channels": { "(기본 채널명)": { "last_message_id": null, "last_run": null } },
  "created": "YYYY-MM-DD"
}
```
`last_message_id: null`이면 첫 배치는 최근 24시간분만 처리한다 (AGENTS.md 배치 절차 참조).

## 4단계 — 일일 배치 스케줄 등록

1. 이 환경에서 Antigravity CLI를 **비대화형으로 실행하는 방법**(프롬프트 플래그 등)을 현재 버전 문서에서 확인하라.
2. OS 스케줄러(Windows 작업 스케줄러 또는 cron)에 매일 `(사용자 입력: 실행 시각, 권장 06:30)` 이 폴더에서 `일일 배치` 명령을 실행하는 작업을 등록하라.
3. 등록한 스케줄 내용과, PC가 꺼져 있던 날은 다음 실행 때 자동으로 따라잡힌다는 점(state.json 기반)을 사용자에게 보고하라.
4. 스케줄러 등록이 권한 등으로 불가능하면: 등록 명령어를 사용자에게 제공하고 수동 등록을 안내하라.

## 5단계 — 검증 (필수)

1. `일일 배치`를 수동으로 1회 실행하라.
2. 확인 항목:
   - [ ] 새 글이 00_원문보관과 해당 테마 문서 **맨 아래에** 추가되었는가
   - [ ] 기존 내용이 수정·삭제되지 않았는가
   - [ ] state.json의 last_message_id가 갱신되었는가
   - [ ] `업데이트`를 곧바로 다시 실행했을 때 **중복 기록이 없는가**
   - [ ] 완료 보고에 "오늘 읽을 문서 추천"이 포함되는가
3. `추가: (사용자가 주는 외부 URL 1개)`로 외부 소스 편입도 1회 테스트하라 (▶ 출처에 URL 표기 확인).
4. 전 항목 통과 시 구축 완료를 선언하고, 사용자 루틴(매일 추천 문서 읽기 + 💭 기록)을 안내하라.

## 구축 후 이 문서의 역할

구축이 끝나면 이 문서는 보관용이다. 재설치·PC 이전 시 다시 사용한다.
운영 중 규칙 변경은 `AGENTS.md`를 수정하면 된다.
